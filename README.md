# Morphological Filters & Spatial Filtering Project

This Machine Vision project demonstrates image enhancement, sharpening, segmentation, and object analysis techniques using Python and OpenCV.

## Project Overview
The project applies spatial filtering and morphological image processing operations to different images including:
- Moon image enhancement
- Fingerprint segmentation
- Cell detection and analysis

## Features
- Laplacian sharpening
- Sobel edge detection
- Histogram-based thresholding
- Morphological opening and closing
- Noise reduction
- Connected component analysis
- Object counting and feature extraction

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Objectives
- Improve image quality using spatial filters
- Detect edges and structures in grayscale images
- Segment fingerprint patterns using thresholding
- Analyze and count objects in biological images

## Results
The project successfully enhanced image details, reduced noise, detected edges, and identified connected regions for image analysis tasks.
